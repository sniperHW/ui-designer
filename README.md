# ui-designer — 手游 UI 雏形设计工具

线框图 + 交互原型设计工具（Electron）。设计文档见 `概念设计.md`，**当前进度与接手要点见 `开发进度.md`**，当前实现为 M0 + M1 + M2。

## 开发

```bash
npm install
npm run dev        # 启动开发模式
npm run typecheck  # TypeScript 检查
npm run build      # 构建产物（out/）
```

## 当前功能（v0.3）

- 内置控件全集：形状（矩形 / 圆角矩形 / 椭圆 / 线段 / 占位图 / 九宫格）、文本、交互（按钮 / 复选框 / 进度条 / 输入框 / 筛选器）、容器（面板 / 弹窗 / 滚动区 / 列表 / 网格 / Tab 页签）
- **容器通用机制**：把控件拖到容器内容区自动挂为子控件（几何落点递归判定，支持嵌套）；移动 / 删除 / 复制容器时子控件跟随；子控件裁剪显示，图层树缩进
- **Tab 容器**：默认 3 页签（可增删改名）；页签栏上 / 下；画布点击页签头切换编辑页
- **定制控件（M2 核心）**：画布组合"存为定制控件"原位替换为实例；以容器为骨架新建；编辑定义全局同步到所有实例；暴露属性（内部子控件属性绑定 + 实例覆盖值）；插槽（Tab 每页签默认开放，面板 / 弹窗 / 滚动区可标记开放，实例可挂内容）；打散实例为普通组合；禁止循环引用；建议锚点（顶部 / 底部拉伸自动吸附）
- **锚点 + 多分辨率预览**：九宫格锚点 × 尺寸模式（固定 / 随父拉伸 / 等比）；状态栏一键切换 16:9 / 18:9 / 19.5:9 / 4:3 只读预览，按锚点规则实时重排；刘海屏安全区参考框
- **筛选器**：标签行单选高亮；项标记 + 绑定列表 / 网格与标记键（预览过滤随 M3 预览实现）
- **启动流程**：打开程序默认未打开工程（欢迎页）；新建（横竖屏/尺寸预设）或打开 `.uiw` 后进入编辑器；未保存修改切换前确认
- **公共层**：工程级共享层，顶部状态栏 / 常驻导航一次编辑、所有页面共享；页面列表顶部"公共层"条目编辑，普通页面中只读，缩略图与导出包含
- 从控件库拖入画布（或点击加到画布中央），选择 / 移动 / 8 向缩放 / 方向键微调
- 多选（Shift / ⌘A）、对齐与分布、图层排序（显隐 / 锁定 / 移层 / 置顶底）
- 页面管理：新建 / 复制 / 删除 / 重命名，缩略图预览
- 网格显示与吸附、滚轮缩放平移、适配窗口
- 撤销 / 重做、复制 / 粘贴 / 再制、删除
- 工程保存 / 打开（`.uiw`，v0.1 为 JSON 明文）、导出当前页 PNG（2x 白底）

## 快捷键

⌘Z / ⇧⌘Z 撤销重做 · ⌘C/⌘V/⌘D 复制粘贴再制 · ⌘A 全选 · ⌫ 删除 · 方向键微调（⇧ ×10）· ⌘S 保存 · ⌘O 打开 · ⌘N 新建 · ⌘= / ⌘- 缩放 · Esc 取消选择

## 结构

```
src/main/       Electron 主进程（窗口、文件对话框 IPC）
src/preload/    contextBridge API
src/renderer/   React 界面
  src/store/editorStore.ts   编辑器状态（文档 + 历史 + 视口 + 定制控件）
  src/widgets/registry.ts    控件定义与 SVG 线框渲染（画布/缩略图/导出共用）
  src/widgets/tree.ts        节点树遍历（容器子树/插槽/克隆换 id）
  src/components/            界面组件
```
