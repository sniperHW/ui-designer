# 卡牌页素材交互装配预览（卡库筛选版）

- 工程文件：`卡牌-素材交互装配预览-卡库筛选版.uiw`
- 源工程：`examples/卡牌.uiw`（未修改）
- 页面尺寸：750 × 1600 设计像素

## 新增节点与真实交互

`页面 1 / 主导航 / 卡牌 / 卡库筛选` 是一个内容型 Tab，位于战力条下方。

它上方的五项负责筛选卡库集合；其下方仍保留原工程的分类 Tab：`所有卡牌 / 神器 / 宝箱 / 表情`。两层控件职责分开，不互相替代。

| 页签 | 皮肤文件 | 切换后的内容 |
| --- | --- | --- |
| 全部 | `library_filter_all_*_120x64.png` | 16 张图鉴卡，可滚动 |
| 骷髅 | `library_filter_skull_*_72x64.png` | 第 1、5、9、13 张图鉴卡 |
| 狼 | `library_filter_wolf_*_72x64.png` | 第 2、6、10、14 张图鉴卡 |
| 头盔 | `library_filter_helmet_*_72x64.png` | 第 3、7、11、15 张图鉴卡 |
| 齿轮 | `library_filter_gear_*_72x64.png` | 第 4、8、12、16 张图鉴卡 |

右侧 `已收集：13/40` 对应运行时文本节点 `已收集统计`；没有画入 PNG。五个筛选皮肤也均为无文字、无数字 PNG，尺寸即节点显示尺寸。

## 使用

在设计工具中打开本目录的 `.uiw`，进入“卡牌”页。点击战力条下方的“全部”或四枚图标，即会切换对应的卡库滚动内容。

所有 PNG 都是页面真实装配尺寸或更小的组件尺寸；不包含生图原始大图。
