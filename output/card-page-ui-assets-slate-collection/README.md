# 卡牌页无字 UI 美术素材：石板蓝卡牌图鉴版

这是在 `石板蓝分级框体版` 之上的可交互图鉴完善版。所有交付 PNG 都是 `.uiw` 真实节点尺寸；图像生成时产生的较大中间图不在本目录交付，也不参与装配。

## 交互预览

打开 `卡牌-素材交互装配预览.uiw`。它保留原 `examples/卡牌.uiw` 的底部导航、牌组选择、卡牌分类与滚动交互；原工程未改动。

- `定位按钮`、`更多按钮`、`录制按钮` 在本预览中已隐藏：它们不属于本页验收范围。
- 四个资源条仍作为公共资源信息存在。
- `游戏卡牌` 保持相同的属性绑定契约（配型、等级、进度、碎片、可升级），但预览内以四个等规格定义轮换稀有度皮肤。

| 素材组 | 文件 | 最终像素 | `.uiw` 对应关系 |
|---|---|---:|---|
| 页面背景 | `page_background_750x1600.png` | 750×1600 | 新增预览最底层 `页面背景素材` |
| 资源信息 | `common_resource_bar_bg_160x44.png`、4 个 `common_resource_*_32x32.png` | 160×44、32×32 | 4 个资源条及其预览图标 |
| 牌组/导航/战力 | `page_filter_*`、`page_power_bar_bg_700x70.png`、`page_sub_tab_*`、`page_main_nav_*` | 各节点原始尺寸 | `牌组选择`、`战力条`、`卡牌分类`、`底部导航` |
| 卡框皮肤 | `card_frame_green/blue/purple/gold_160x220.png` | 各 160×220 | 四个 `游戏卡牌（颜色）` 定义中的 `卡框` |
| 卡面 | `card_art_green/blue/purple/gold_112x96.png` | 各 112×96 | 四个 `游戏卡牌（颜色）` 定义中的 `卡面图片` |
| 卡牌共用状态 | `card_role_badge_34x34.png`、`card_progress_*_136x26.png`、`card_upgrade_badge_38x26.png` | 节点原始尺寸 | `配型底`、`碎片进度条`、`可升级标识` |
| 兵种统计图标 | `stat_icon_*_24x24.png` | 各 24×24 | 战力条原 `兵种统计` 位置新增的 6 个预览图标节点 |

所有 PNG 无文字与数字。资源数值、加号、战力值、兵种数值、Tab 名称、配型、等级、碎片及升级状态均继续由运行时 `.uiw` 节点绘制。
