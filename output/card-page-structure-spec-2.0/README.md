# 卡牌页结构规范 2.0（巨像文明）

工程文件：`卡牌页-结构规范2.0.uiw`。设计尺寸为 750 × 1600 竖屏，源自已验证的卡库筛选交互工程；旧工程和已装配预览均未覆盖。

## 2.0 修订内容

| 区块 | 2.0 规范 |
| --- | --- |
| 顶部牌组区 | 拆成 `牌组标题底板`（140 × 64，x25）与 `牌组编号切换`（5 项、550 × 64，x175）；避免把标题误当成第六个编号 Tab。 |
| 首屏卡牌 | 保持 4 × 2、160 × 220；卡面窗调整为定制控件内的 136 × 112，增强角色内容占比。 |
| 战力与筛选 | 保留战力条、可切换卡库筛选栏、已收集统计与下方分类 Tab 的双层职责。 |
| 卡库与底栏 | 保留滚动卡库、`所有卡牌 / 神器 / 宝箱 / 表情`，以及五格主导航。 |

## 后续素材契约

- 新卡面素材应按 **136 × 112** 交付；等级、碎片、数值均由运行时文本渲染。
- 标题底板：140 × 64；牌组编号按钮：110 × 64 × 5（普通与选中态）。
- 金属框体采用三级层级：主容器 > 卡牌/选中态 > 分隔线；不要所有边框同样加粗或同样高亮。
- 首屏至少准备 8 张不同卡面；卡库首屏准备 8–12 张不同卡面，避免重复角色破坏收集感。

在工具中打开 `.uiw` 后，进入“卡牌”页即可检查 2.0 结构；卡库筛选继续真实切换其对应的卡牌集合。
