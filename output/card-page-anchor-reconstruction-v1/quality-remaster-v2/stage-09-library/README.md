# v2 阶段 09：卡库区

本阶段只处理卡库滚动容器，已通过的卡牌框、四种稀有度立绘、种族筛选和底部主导航均从上一阶段真实复用，禁止重绘或把卡牌烘焙进容器皮肤。

卡库滚动区是无固定背景框的真实 Scroll：卡牌直接在页面背景上滚动，避免固定底边遮挡或裁切最后一行卡牌。

装配时保留种族切换、卡牌子节点和 Scroll 节点。旧工程中间的“卡库分类 Tab”会被扁平化：每个种族页直接挂接其真实滚动卡库，避免工具画布对嵌套 Tab 的呈现失效；滑块继续由真实 Scroll 控件绘制，因此卡库不是一张静态截图。

切页栏作为与种族筛选并列的真实 Tab（所有卡牌 / 神器 / 宝箱 / 表情），不再额外包裹 Scroll。每项与种族筛选共用同一套默认态／选中态底板素材家族：从筛选栏的 `72×64` 源皮肤以九宫格扩展为 `169×84`，保留相同圆角、边框与像素密度，绝不拉伸角部。文字不参与渲染，四项改用独立的 `48×48` 暖金单色透明图标。选中态只切换框体皮肤，图标本身无底图。该结构避免“筛选 Tab → 切页 Tab → Scroll”的双层嵌套导致工具画布空白，同时保留切页栏自身的页签状态与点击语义。

验收门禁：切页框体四边完整、四角真实 alpha、边缘无暗底/锯齿/裁切；卡牌可见且不被固定框体覆盖；种族页、切页栏和滚动交互均保持为真实控件。

结构门禁：当筛选器本体是带内容页的 `Tab` 时，节点尺寸必须是完整卡库容器 `700×700`，不能写成顶部按钮栏 `408×64`。顶部按钮的可视宽度由 `tabWidths` 控制；若错误缩小容器本体，工具会将内容裁成 `408×32`，即使卡牌节点存在也完全不可见。
