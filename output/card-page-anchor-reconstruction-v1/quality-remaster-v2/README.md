# 卡牌页全素材质量重制 v2

本目录不覆盖 `stage-01` 至 `stage-05` 的已验收基线。它以 [素材质量标准](../素材质量标准.md) 为唯一验收流程，将所有基线素材重新纳入“结构、精修、透明、边缘、尺寸、装配”闭环。所有独立图标遵循“透明图层直接叠加于完整容器底板”的规则，禁止以局部纯色补片模拟图标底座。

## 审计与重制顺序

| 类别 | v1 基线 | v2 处理结论 | 状态 |
|---|---|---|---|
| 页面背景 | `stage-03-background` | 无文字、无外部透明边、缩放纹理连续；保留结构，进行版本化规范输出 | 已完成首轮审计 |
| 牌组标题与编号皮肤 | `stage-01-deck-v2` | 金属轮廓闭合、切角和透明边缘干净；保留结构，进行版本化规范输出 | 已完成首轮审计 |
| 右对齐资源组 | `stage-02-resources` | 四条资源皮肤轮廓完整，动态数值未烘焙；保留结构，进行版本化规范输出 | 已完成首轮审计 |
| 四稀有度卡框与进度组件 | `stage-04-cards` | 锚点提取后存在最容易暴露边缘/渐变瑕疵的风险；进入 ImageGen 精修与真实透明化 | 进行中 |
| 战力条 | `stage-05-battle` | 已完成 ImageGen 精修、真实透明化、上下边缘渐变重建 | 已通过，作为 v2 标准样板 |
| 筛选、分类 Tab、底部导航 | 后续未重制类 | 按同一流程在卡框通过后推进 | 待开始 |

## 不可变约束

- `.uiw` 节点尺寸、运行时文字、Tab、筛选和滚动交互不为迁就素材而改变。
- `游戏卡牌` 继续为 `160×220`，并复用既有角色立绘；精修仅处理无字卡框、角标、进度与升级状态皮肤。
- 每一类 v2 素材单独装配、截图验收，通过后才允许进入完整 v2 页面。
