# v2 阶段 04：卡框精修（绿色样板）

此关只验证绿色稀有度无字卡框。生成候选在规范化后必须满足：

- 外框 `160×220`；外部为真实透明；无黑边、灰边、白底或棋盘残留。
- 卡面窗强制为 `x=12, y=38, w=136, h=112` 的真实透明区。
- 等级带与碎片进度位置保留给现有 `.uiw` 节点，PNG 不包含文字、数字、徽标、角色或进度填充。
- 通过真实装配后，才会按同一方法处理蓝、紫、金三种稀有度。

## 卡面覆盖契约（适用于全部角色立绘）

卡面窗固定为 `x=12, y=38, w=136, h=112`。所有立绘先由
`build_card_family.py` 以 `fit: cover` 裁切到精确 `136×112`，再以
`backdrop_color` 合成稀有度匹配的卡面底衬，最后以
`require_opaque: true` 验证整张图片的 alpha 为不透明；构建失败就不能
装配。装配器只绑定这份规范化结果，并再次写回同一窗口尺寸。因此角色
画面不会因为原图比例或透明通道而露出卡框/页面底色。

## 卡牌层级契约

卡面窗与种族徽章在左上角存在约 `4px` 的几何交叠，渲染顺序必须固定为：
`卡面图片 → 卡框 → 配型底 → 配型图标 → 运行时等级/进度/升级标`。
若将卡面放在徽章之后，卡面会裁掉徽章的下沿，属于构建不通过。

## 种族图标复用契约（临时映射）

卡牌左上角不再使用文字或 Emoji 占位，直接复用筛选栏已经验收的透明 PNG：
`shared_race_undead_64.png`、`shared_race_orc_64.png`、
`shared_race_human_64.png`、`shared_race_mechanical_64.png`。当前仅为视觉验证，
暂按绿/蓝/紫/金卡框依次映射为亡灵/兽人/人类/机械；正式卡牌归属确定后，
只修改各装配清单的 `card_faction_icons`，不制作、复制或烘焙新图标。

## 框体展示底清除契约

生图候选中的棋盘/白底有时会停留在框体的内侧分隔带，即使它们不是透明
通道。必须以锚点测得的矩形指定 `neutral_recolor_rects`，只把该区域的中性
白色改为对应卡框的结构色；不得用泛化的全图去白破坏金属高光。绿色样板
的上、下内侧带分别是 `y=28–37` 与 `y=150–157`。
