# v2 阶段 08：底部主导航

主导航采用无字框体与独立透明图标的分层合同：框体只承担金属描边、深蓝面板和
选中暖金状态；五个图标分别叠加，`tabs` 仍保留真实页签语义和切换关系，但不在
图标上重复渲染文字。

五项必须复用同一个完整四边框 PNG，并以 `146px` 宽、`5px` 固定留缝排布。
不允许把含有相邻分隔线的横向裁片重复作为单按钮皮肤；相邻皮肤零间距紧贴会让
左右边框叠成双线，属于构建失败。

每份素材在绑定前均通过 alpha 覆盖率和外缘暗底门禁。生成源图只用于修复无图标
框体与图标候选；进入 `.uiw` 的是按真实 `150×110` 与 `48×48` 尺寸规范化后的 PNG。
