# Stage 16：巨像文明 V8 运行时素材

本阶段以用户确认通过的 V8 风格图为视觉基线，将页面拆成可复用、可验收的运行时素材；不从整页风格图直接裁切成最终资产。

## 输入

- 结构事实源：`../stage-09-library/卡库区-v16-累计装配预览.uiw`
- 风格基线：`../stage-15-contract-style-image/巨像文明-卡牌页-装配合同风格图-v8-final-750x1600.png`
- 装配合同：`../stage-15-contract-style-image/风格图装配合同.json`
- 通用质量：仓库根目录 `素材质量基线.md`
- 专用风格：本目录 `巨像文明卡牌页-专用美术风格标准-v1.md`

## 固定流程

1. 按 `asset-plan.json` 只生成有消费者的唯一素材。
2. 框体、图标、文字、数值、进度和状态高光保持独立职责。
3. 候选素材通过 RGBA、真实 alpha、闭合轮廓、边缘和尺寸门禁后才能绑定。
4. 从 V16 复制生成新的装配候选，不覆盖 V16 或任何已确认版本。
5. 新候选通过 UIW 校验并在真实设计工具画布验收后才可交付。

## 背景决策

不生成 750×1600 整页背景图。UIW 使用深海军蓝运行时底色；H5/引擎可选用 128×128 低频微纹理平铺，但不得在不支持平铺的渲染器中拉伸。
