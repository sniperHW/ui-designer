# 牌组按钮 v5：透明盾牌图标

牌组编号按钮遵循透明独立图标规范：按钮底板不含盾牌槽，金色盾牌以独立透明
`44×44` PNG 叠加；罗马数字仍由真实 Tab 控件运行时渲染。选中态只改变完整按钮
底板的金属色相、内衬亮度与暖金高光，不新增盾牌底座或其他局部补片。标题“牌组”仍由
`牌组标题文字` 运行时节点渲染，不能烘焙进底板。

本预览也显式绑定 `stage-02-resources-v3` 的最新资源条与四个透明图标，避免牌组
按钮阶段回退到旧的烘焙黑框资源素材。

牌组标题框同样纳入外沿深色哑光质量门禁：构建时先清除展示底，再检测是否仍有从
画布外侧可连通的可见近黑像素；检测不通过时不会产出装配文件。
