# 生成 .uiw 设计工程

为「手游 UI 雏形设计工具」生成可直接打开的 `.uiw` 工程文件。`.uiw` 是一份 JSON 文档（`ProjectDoc`），用写文件工具即可产出，无需运行编辑器。

**本 skill 目录**（下文相对路径均基于此）：本 SKILL.md 所在目录。

## 工作流（必须按顺序完整执行）

1. **明确需求**：屏幕方向与设计尺寸（横屏 1334×750 / 竖屏 750×1600 等）、页面清单、每页的内容结构。用户未指定时按内容量自行选择并说明。
2. **读规范**：先读 `references/schema.md`（文档结构与字段约束），再读 `references/widgets.md`（19 种控件的默认尺寸、props、容器语义）。不要凭记忆写格式。
3. **生成 .uiw**：
   - 简单布局：直接写出完整 JSON（2 空格缩进，UTF-8，扩展名 `.uiw`）。
   - 复杂/重复布局（网格排布、等距堆叠、批量卡牌）：写一个**临时 Node 脚本**计算坐标并 `JSON.stringify(doc, null, 2)` 落盘，跑完即可丢弃脚本，只保留 `.uiw`。
4. **校验（必做）**：
   ```bash
   node <本skill目录>/scripts/validate.mjs <输出文件.uiw>
   ```
5. **修复循环**：按 `✗` 报错（含节点路径与原因）修改后重跑，直到 `✓` 通过；`⚠` 警告需逐条确认是否合理（如滚动区内容故意溢出属正常）。
6. **交付**：告知用户在编辑器中 `⌘O` 打开该文件验收；如有预览诉求提示用「视图 → 分辨率预览」。

## 硬性规则（违反会被校验器拒绝或导致显示异常）

- 所有节点 `id` 全文档唯一；页面 id 同样唯一。
- 坐标为**设计像素**、页面绝对坐标；`w`/`h` 必须 > 0；对齐 10px 网格。
- 同一页的 `nodes` 数组顺序 = 绘制顺序，**数组靠后 = 显示在上层**；背景放最前，弹窗/浮层放最后。
- 结构归属：`pages` 仅 tab；`children` 仅 panel/dialog/scroll；`slots`/`customId` 仅 custom；`binding` 仅 filter。`list`/`grid` 的项是占位格，**不能挂子控件**（要自定义格子内容就用 `scroll` 手摆）。
- tab 的 `pages` 数组长度 ≤ `props.tabs` 长度，每项是一个子树数组；容器子控件会被裁剪到内容区（tab 内容区在页签栏之外，dialog 在 48px 标题栏下方）。
- 定制控件定义树内坐标**相对 (0,0)**；实例的 `slots` 子控件是**页面绝对坐标**；插槽键 = `<容器节点id>` 或 `<Tab容器节点id>:<页签下标>`（键列表可先跑校验器从报错提示中获得）。
- 生成的节点一律 `visible: true, locked: false`。
- `customId` 只能引用 `customWidgets` 中存在的定义，且定义间不得循环引用。

## 布局惯例

- **公共层**（`commonLayer`）放所有页面共享内容：顶部状态栏/资源栏（`anchor: {preset:"tc",mode:"stretch"}`）、底部常驻导航（`bc` + `stretch`）、悬浮球（四角 `fixed`）。
- **页面骨架**常用：标题区 → 筛选器 → 列表/网格 → 底部 Tab 导航；弹窗类内容放 `dialog` 容器。
- 可滚动的长内容放 `scroll` 容器，子内容高度超出容器即被裁剪，正好示意"可下滑"。
- 字号：页面标题 40 左右加粗、区块标题 28–32、正文 24–26、辅助说明 20–22；按钮文字 26–30。
- 间距以 20/24/40 为常用档；卡片间距 16–24；左右边距 40。
- 参考完整示例：`examples/最小工程.uiw`（覆盖公共层、定制控件实例+暴露属性覆盖、筛选器↔列表联动、底部 Tab 多页签）。

## 校验器说明

- `✗` 错误必须清零；`⚠` 警告逐条判断（超出设计尺寸、页签数组不匹配、itemTags 多于 count 等）。
- 校验通过 ≠ 视觉合理：交付前自查一遍坐标是否重叠/越界、层级顺序是否符合常识。
